# تجربة الري — Offline Web App

تطبيق ويب يعمل **بدون إنترنت** بعد أول فتح (PWA).

## الملفات

| الملف | الوصف |
|--------|--------|
| `index.html` | التطبيق الكامل |
| `manifest.json` | تثبيت على الشاشة الرئيسية |
| `sw.js` | Service Worker للتخزين المؤقت دون اتصال |
| `assets/icons/` | أيقونات Android / iOS |

## الاستخدام محلياً

افتح عبر خادم بسيط (مطلوب لـ Service Worker):

```bash
cd irrigation-offline
python3 -m http.server 8080
```

ثم افتح: http://localhost:8080

## GitHub Pages

ارفع محتويات المجلد إلى المستودع وفعّل Pages من الفرع الرئيسي.

## ملاحظات

- بعد أول فتح **مع إنترنت** تُخزَّن الصفحة ومكتبة Excel إن أمكن.
- لاحقاً يعمل الإدخال والملخص والمنحنى **أوفلاين**.
- تصدير Excel يعتمد على مكتبة SheetJS (تُحمَّل أول مرة ثم تُخزَّن).
